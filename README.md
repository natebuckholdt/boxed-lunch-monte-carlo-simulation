# Boxed-Lunch Monte Carlo Simulation

Excel Monte Carlo simulation comparing a 230-lunch Conservative Order and a 270-lunch Large Order under uncertain demand and preparation costs.

## Recommendation
The Large Order was recommended because it produced higher average profit and substantially fewer lost sales, despite creating more leftovers.

- Microsoft Excel
- Monte Carlo simulation
- Decision analysis
